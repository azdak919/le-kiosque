## Français

### 1. Exception pour les sites des journaux

Le Kiosque fabrique le site public d’un journal. Pour ce faire, la commande de
construction recopie des parties du Kiosque dans le dossier de sortie du
journal : gabarits, feuilles de style, scripts du thème, images et, le cas
échéant, l’admin de rédaction du Socle. Ce dossier est souvent `dist/`.

Le titulaire du droit d’auteur, Azdak, accorde la permission suivante : les
fichiers que le Kiosque produit ou recopie dans le site d’un journal, qu’ils
soient modifiés ou non, peuvent être utilisés, modifiés, hébergés et diffusés
selon les conditions choisies par le journal, sans obligation de l’AGPLv3.
Le journal n’est notamment pas tenu de publier le code source de son site,
même s’il en a modifié le thème.

Cette permission couvre aussi le code de LE-RADAR repris dans le thème, du
même auteur.

### 2. Ce qui reste sous AGPLv3

Le Kiosque lui-même reste sous AGPLv3 : moteur de construction, adaptateurs,
configurateur, outils et thème tel qu’il est distribué dans ce dépôt.
Quiconque distribue une version modifiée du Kiosque, ou la fait tourner comme
service en réseau, doit en offrir le code source.

### 3. Contributions et retrait

En proposant une contribution à ce dépôt, son auteur accepte qu’elle soit
distribuée sous l’AGPLv3 et sous cette permission. Conformément à l’article 7
de l’AGPLv3, quiconque redistribue une version modifiée du Kiosque peut
retirer cette permission de sa copie.

## English

### 1. Exception for newspaper sites

Le Kiosque builds a newspaper’s public site. To do so, the build command copies
parts of Le Kiosque into the newspaper’s output directory: templates,
stylesheets, theme scripts, images and, where applicable, the Le Socle editorial
admin. That directory is often `dist/`.

The copyright holder, Azdak, grants the following permission: the files that
Le Kiosque produces or copies into a newspaper’s site, modified or not, may be
used, modified, hosted and distributed on terms of the newspaper’s choosing,
free of the AGPLv3’s obligations. In particular, the newspaper does not have to
publish the source code of its site, even if it has modified the theme.

This permission also covers LE-RADAR code reused in the theme, which has the
same author.

### 2. What stays under the AGPLv3

Le Kiosque itself stays under the AGPLv3: the build engine, adapters,
configurator, tools and the theme as distributed in this repository. Anyone who
distributes a modified version of Le Kiosque, or runs one as a network service,
must offer its source code.

### 3. Contributions and removal

By submitting a contribution to this repository, its author agrees that it may
be distributed under the AGPLv3 and under this permission. As section 7 of the
AGPLv3 allows, anyone who redistributes a modified version of Le Kiosque may
remove this permission from their copy.
