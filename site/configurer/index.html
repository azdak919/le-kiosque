Dites où le journal vivra. Le site public est publié par GitHub Pages ; les articles s’écrivent dans le socle, un petit serveur à installer chez un hébergeur : télécharger le paquet PHP (voir le guide étudiant).

1. Fichiers du dépôtLes fichiers du journal (fiche, sections, couleurs, logo), à déposer à la racine de votre dépôt GitHub.
2. Réglages du socleDans l’admin du socle : Configuration → « Importer le fichier du configurateur ». Rien à ressaisir. (Sert aussi à l’extension WordPress.)
