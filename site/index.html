Comment ça marche

Quatre étapes, aucune connaissance technique.

  1. 1

    Vous le personnalisez

    Vous choisissez le nom, le logo et les couleurs de votre journal.

  2. 2

    Vous écrivez

    Vous rédigez vos articles dans un éditeur simple, comme un document.

  3. 3

    C’est en ligne

    Le journal se publie sur le Web tout seul, sur ordinateur comme sur téléphone.

  4. 4

    Rien ne se perd

    Tous les numéros restent archivés pour la cohorte suivante.

Pour les responsables techniques

Les articles sont écrits en Markdown et conservés dans un dépôt Git que l’équipe possède. Le site est produit en HTML statique, publiable sur GitHub Pages, avec une extension WordPress ou un kit portable. Code sous licence GPL-2.0, aucune dépendance à un service externe.
