Kit d’Infrastructure Ouverte, Souveraine et de Qualité pour les Usages Éditoriaux

Un seul fichier à déposer chez un hébergeur. Un assistant s’ouvre dans le navigateur. Le site Web public et l’espace de rédaction sont prêts, sans aucun serveur central.

Mise en route

Quatre étapes, dans le navigateur.

Il faut un hébergement PHP 8.1 ou plus récent, avec SQLite : le serveur du cégep ou de l’association, un hébergeur habituel, ou un essai gratuit chez alwaysdata. Ni compte GitHub, ni ligne de commande.

  1. 1

    Téléchargez le paquet

    Un seul fichier, kiosque-journal.zip, toujours à la même adresse : la dernière version publiée.

  2. 2

    Déposez-le chez l’hébergeur

    Envoyez le contenu du dossier kiosque-journal/ à la racine de l’espace Web, par exemple dans public_html/. Le site sera à https://votre-journal.com. Un sous-dossier reste possible si vous le souhaitez. Le gestionnaire de fichiers peut souvent extraire le ZIP directement.

  3. 3

    Remplissez l’assistant

    Ouvrez https://votre-journal.com/redaction/. Donnez le nom du journal, les rubriques, un logo au besoin, et créez le compte administrateur.

  4. 4

    Écrivez, puis publiez

    L’article paraît tout de suite sur le site. Une sauvegarde se télécharge en un clic ; une mise à jour aussi, quand une version est publiée.

Le site Web public

Un journal, pas une page d’accueil générique.

Sans logo, le nom du journal s’écrit en grand dans le mât, dans une police de titre. S’il y a un logo, le logo remplace le nom. On peut choisir plusieurs photos de mât, affichées dans un ordre aléatoire ; un bouton les fait défiler. Les articles portent toutes leurs signatures, avec le crédit et la licence de chaque photo.

Rubriques, recherche et mode sombre

Le menu suit les sections du journal. Une loupe cherche dans les titres, les signatures, les rubriques et les extraits déjà affichés. Un bouton passe du mode clair au mode sombre.

Météo, sports et radio

Le mât peut afficher la météo locale et les résultats sportifs du campus. La barre radio, facultative, est le module radio du Radar, avec ses vraies radios. Ce n’est pas une station du journal : stations, lecteur et style restent chez le Radar.

Équipe et archives durables

Chaque signature a sa page. Sur la démonstration en site statique, et sur un site construit pour GitHub Pages, s’ajoutent les archives, le plan du site et un fil RSS.

Une copie autonome

Après le téléchargement, rien ne dépend d’un serveur du Kiosque. Le journal reste en ligne même si ce dépôt change, ou s’il s’arrête.

L’espace de rédaction

Écrire, relire, publier, à plusieurs.

L’espace de rédaction, c’est le Socle : l’interface d’administration et son serveur, livrés dans le même paquet. Chaque journal installe sa propre copie. Les captures ci-dessous viennent du Quorum, la démonstration officielle, et de l’assistant d’installation.

La sauvegarde complète se télécharge en un fichier ZIP (articles, photos, équipe et réglages, sans les mots de passe). On peut la restaurer plus tard. Quand une version de la plateforme est publiée, la page Mise à jour la propose, en un clic. Pour en savoir plus sur le programme lui-même : la page du Socle.

Pour un professeur, une équipe, un essai

Voir, puis installer.

Le Quorum est la démonstration officielle, déjà en ligne. La Vigie est un journal fictif installé chez un hébergeur gratuit, pour vérifier le paquet de bout en bout. Le guide d’une page tient sur une feuille, pour un étudiant qui n’a jamais rien installé.

D’autres chemins existent, documentés dans le guide étudiant complet : site public sur GitHub Pages, serveur de l’établissement, auto-hébergement. Une extension peut aussi préparer un WordPress neuf ; l’écriture depuis WordPress vers le Kiosque n’est pas encore offerte. Le configurateur en ligne reste disponible pour qui prépare une fiche avant l’installation.

Le paquet complet

Installer son journal aujourd’hui.

Téléchargez kiosque-journal.zip, déposez-le chez l’hébergeur, ouvrez l’assistant. Comptez une vingtaine de minutes la première fois.
